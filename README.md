## ✨ Features
 
- Responsive design — works on mobile, tablet, and desktop
- Smooth scroll navigation between sections
- Projects section with tech stack tags
- Skills section with categorised technologies
- Contact section with links to email, LinkedIn, and GitHub
- Built with React component-based architecture

## 🚀 Run Locally
 
Follow these steps to run the project on your own machine:
 
```bash
# 1. Clone the repository
git clone https://github.com/mearning7905-debug/Portfolio__Website.git
 
# 2. Go into the project folder
cd Portfolio__Website
 
# 3. Install dependencies
npm install
 
# 4. Start the development server
npm run dev
```
 
Then open `http://localhost:5173` in your browser.
 
---
 
## 📦 Build for Production
 
```bash
npm run build
```
 
This creates an optimised `dist/` folder ready to deploy.
